# BibleOS version 2 backlog

Features saved for after the 1.0 launch. Each one still goes through the `architect-feature` plan before any code. Order is a rough priority, not a commitment.

## Reading and study

- **Cross-references.** Tap a verse to see related passages, from an openly licensed cross-reference set (for example OpenBible.info's, CC BY). Stored as a read-only table built by `bible-data`, keyed by canonical `VerseId`.
- **Import your own Bible files.** Let a reader add a USFM or OSIS translation they own. It's parsed with the same `bible-data` code, stored in the app data folder and never bundled or shared. This is also the route for licensed texts such as the Amharic 2005 (አዲሱ መደበኛ ትርጉም) once the files and permission are in hand; see `.artifacts/research/06-amharic-2005.md`.
- **Online Bible providers.** Optional translations fetched through an official API (API.Bible or YouVersion Platform), with keys in the OS keychain, plus whatever offline caching the licence allows.
- **Memorization.** Verse cards with spaced review, linked to the habit tracker.
- **Audio Bible.** Needs an openly licensed recording, with playback that follows the reader.
- **Partial-verse highlights.** Highlight a phrase rather than the whole verse, using character offsets that fall back to the whole verse in other translations.

## Habits and personalisation

- **Named highlight colours**, such as "Promises" or "Prayer", with filtering in Study.
- **Month and week habit views** next to the year heatmap.
- **Streak visibility:** decide whether Today shows the streak prominently or keeps it low-key.

## Product and platform

- **UI polish pass:** spacing, empty states, motion and Amharic layout on every screen.
- **Amharic copy review** of `apps/desktop/src/i18n` by a native speaker.
- **Sync between devices (optional)** through the kept SaaS starter as a sync server, opt-in only. The `change_log` table already records every change for this.
- **Tablet and mobile** (Tauri mobile or the Expo app), sharing `bible-core` and `local-api`.
- **Code signing** (Apple Developer ID and a Windows certificate) to remove the first-install warnings, if the project ever pays for them.
- **Windows on ARM and Linux ARM** installers.
